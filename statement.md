# Project Statement

## Project Title

Student Expense & Budget Management System

## Problem Statement

Students often have difficulty keeping track of their daily expenses and controlling their monthly spending. Manual recording can make it difficult to calculate total expenses, identify spending patterns, and determine whether the monthly budget is being followed.

The Student Expense & Budget Management System provides a command-line application that allows students to record, manage, search, and analyze their expenses while maintaining monthly budgets.

## Objectives

The main objectives of the project are:

1. To provide a simple system for recording student expenses.
2. To store expense information persistently using JSON files.
3. To allow users to view, search, and delete expenses.
4. To calculate total and monthly spending.
5. To allow users to set monthly budgets.
6. To monitor budget usage and remaining amounts.
7. To provide category-wise and monthly expense reports.
8. To demonstrate Python programming concepts through a modular application.

## Main Functionalities

### 1. Expense Management

The system allows users to:

- Add expenses.
- View all expenses.
- Delete expenses.
- Search expenses.
- Calculate total spending.

### 2. Budget Management

The system allows users to:

- Set a monthly budget.
- View the budget for a selected month.
- Calculate remaining budget.
- Calculate percentage of budget used.
- Display budget warnings.

### 3. Expense Reporting

The system provides:

- Monthly expense reports.
- Category-wise spending totals.
- Highest expense.
- Lowest expense.
- Average expense.
- Category spending percentages.

## Input

The application accepts user input through the command line, including:

- Expense amount
- Expense category
- Expense description
- Expense date
- Expense ID
- Month
- Monthly budget amount
- Search keywords

## Output

The application displays:

- Expense records
- Search results
- Total spending
- Monthly spending
- Budget status
- Remaining budget
- Budget usage percentage
- Expense reports
- Validation and error messages

## Data Storage

Expense data is stored in:

`data/expenses.json`

Monthly budget data is stored in:

`data/budget.json`

## Expected Outcome

The completed application provides students with a structured way to record and analyze expenses and monitor monthly budgets through a command-line interface.

The project also demonstrates practical use of Python programming, modular design, file handling, object-oriented programming, validation, exception handling, and testing.
